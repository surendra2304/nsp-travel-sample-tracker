# NSP Travel & Sample Tracker | WhatsApp Editor

A fast, professional, single-column text editor website designed specifically for field travelers, technicians, and sample collectors to log stops, compute kilometers, and copy formatted messages directly into WhatsApp.

---

## ✨ Features

- **⚡ Centered Quick Entry Flow**:
  - Center input box for maximum typing speed.
  - Step 1: Type Place Name → press `Enter` ↵.
  - Step 2: Type Kilometers (KM) → press `Enter` ↵.
  - Loops automatically to the next place without needing a mouse.
- **🏁 End Route Button**:
  - Finish your route at the last place (e.g. `Room`) without having to enter any kilometers for it.
- **🏷️ Customizable Quick Select**:
  - Defaults to **Lab** and **Room**.
  - Click **"+ Add more"** to add custom frequent places that persist in your browser.
- **🔢 0 Default for Collected Samples**:
  - Samples start cleanly at `0` with quick `+` and `−` increment buttons.
- **📐 Column-Aligned WhatsApp Formatting**:
  - Formatted strictly on 2 lines per stop.
  - The hyphens align vertically into a single column with a small gap past the longest place name (like `Kalavapudi modi`).
  - Blank line below the date.
  - Blank line above `Total Distance` and `Collected samples`.
  - Exactly 3 spaces after the hyphen (`-   8`).
- **📋 1-Click Copy**:
  - Prominent **"Copy for WhatsApp"** button with confirmation toast.
  - Direct **"WhatsApp"** share button.
